# ChangeTracker 帮助

开发预览版的离线指南。本应用只观察配置，不修改 Windows，不修复电脑，也不判定电脑是否安全。

## 语言

在左侧选择语言。选择会保存，并即时更新界面、已打开的帮助、日期和文本报告，不重启、不采集。二十种语言全部离线内置。阿拉伯语、埃及阿拉伯语和乌尔都语内容从右向左显示，语言菜单仍在左侧。

应用名称、用户输入的检查点名称、路径、标识符及原始观测值不翻译。JSON/CSV 保留稳定的英文字段。Windows 和 UAC 对话框使用系统语言。正式发布前仍需母语使用者审校。

## 开始使用

1. 正常打开，不要以管理员身份启动。
2. 新用户默认勾选当前用户和整个计算机。可以保留任一项或两项，不能全部清除，然后确认。
3. 检查数据源。网络和 PATH 为可选项，改变选项不会开始检查。
4. 选择今天（新检查），再选择立即检查。

第一次可用观测成为该范围及权限的基准。它是当前清单，不能重建过去。应用不会在启动时自动采集，也不持续监控。

## 简单与高级

简单显示摘要和文本报告。高级增加所有已采集字段、完整前后值、技术元数据以及 JSON/CSV。两个模式都可比较日期、管理历史和选择数据源。

切换模式不采集、不提权、不移动基准、不额外收费。计划一次性售价 0.99 美元，包含两个模式；预览版没有购买功能。

## 独立范围

用户范围读取本用户应用注册、Run/RunOnce、默认关联、音频、代理和 PATH。计算机范围读取共享注册、服务、任务、更新、驱动、防火墙、DNS/DHCP 和系统 PATH。不加载其他人的私人配置文件。

两项均选中时，分别读取再保存为合并快照。仅机器部分可在明确请求后使用管理员权限，用户部分始终使用原来的普通账户。保留已保存的范围及各范围来源偏好。

## 日期与观测

日期按本地日历日筛选，还需选择准确时间和检查点，同一天可有多个快照。基准按钮只选择普通权限的基准，不替换它。仅当前状态会清除前一个选择。

没有快照的日期无法重建，也不会悄悄换成最近一天。两次观测必须不同、按时间顺序、不重叠，且范围和访问权限一致。

## 两个已保存快照

选择前一个日期和快照，再选择已保存快照及后一个日期和快照。比较快照不会运行采集器、请求 UAC 或创建新记录。基准不变，同一天不同时间也能比较。

## 快照与今天

选择以前的快照与今天。立即检查会创建全新观测，并与明确选中的快照比较，不会暗中换成其他基准。成功后选择面板折叠，可随时重新展开。

管理员基准不会自动提权。必须使用独立管理员操作，或只记录当前状态。取消或在采集中关闭会请求停止，保留之前的历史。

## 管理员访问

许多共享设置普通用户即可读取。不能访问的来源会显示覆盖缺口。管理员检查需要明确点击、默认否的确认及一次性 Windows UAC 授权。

主窗口保持普通权限。临时只读辅助进程读取机器配置，不安装服务或留下永久授权。拒绝不会修改基准或历史。不要分享密码或关闭组织安全策略。应用无法关闭已显示的安全桌面 UAC，须在 Windows 中回应。

## 查看详细变化

已添加、已移除和已修改描述两个观测端点的差异，不代表确切时间、作者或原因。重要和需检查是优先级，不是恶意软件判定。常规/预期及影响未评估变化分组显示。标题计数遵循当前筛选，可显示前三项以外的所有发现。

高级显示长值、未变化上下文、新增/删除字段、来源和记录身份。元数据包括快照 ID、范围/权限、快照与来源读取的准确 UTC 时间、版本、状态及数量。空值和不存在不同。未保存过的命令无法恢复，比较指纹和密钥永不显示。设备身份可能识别您，复制前请检查。

预期标记仅适用本次事件且可撤销。打开设置只打开允许的 Windows 工具，不执行修复。

## 覆盖与不确定性

成功是已实现子范围完整，并非检查了全部 Windows。部分表示缺项或达到安全限制，失败表示不可用读取，禁用/范围外表示未读取。不能根据不完整数据推断删除。

本次读取完整仍可能与上次不完整或格式/密钥不同的记录无法比较。合并范围中任一部分不完整会使该类别为部分状态。覆盖详情保留基准和未变化区域。没有差异不等于安全或因果结论。

## 基准与历史

快照页可查看、命名（1–120 字符）、删除或经确认更改基准。删除基准前必须选择其他基准。用户、机器、合并范围、不同权限及旧版混合记录分别保留基准。

无自动清理或固定检查点上限。所有来源均不可用时不保存。清除历史经确认删除快照和标记，保留偏好及密钥，不改 Windows 或已导出文件；不是取证级擦除。

## 来源与限制

| 来源 | 限制 |
| --- | --- |
| 应用与启动 | 卸载注册和 Run/RunOnce；不枚举 Store、便携应用、启动文件夹。注册不是执行证据。 |
| 服务与任务 | 可读配置；不执行，不保存命令或完整 XML，不持续轮询。 |
| 更新与驱动 | 本地成功历史，最多 5,000 事件，超限为部分；WMI 元数据，无安装、固件探测或回滚。 |
| 默认应用与音频 | 支持的文件关联和默认设备，无录音或改动。 |
| 保护 | 防火墙配置，不是杀毒评估。 |
| 网络与 PATH | 可选代理或 DNS/DHCP 与持久 PATH；无抓包、密码、网络探测或其他环境变量。 |

每来源最多 25 秒。清单界面每来源显示最多 1,000 条，实际已采集数据全部保存。只读允许写应用自身历史和请求的导出，不修改被观察设置。

## 报告

报告使用当前显示结果，不是尚未执行的日期选择。两个模式都可预览、复制、保存文本，高级增加 JSON/CSV。文本随语言，结构化格式不变，无自动发送。

报告不含密钥、指纹、启动内容、检查点名称及音频端点 ID。用户路径和常见凭据模式会隐藏，CSV 防止公式执行。可识别名称仍可能保留。没有 PDF/HTML、导入、加密支持包。清除历史不会删除导出。

## 隐私与存储

通常路径为 `%LOCALAPPDATA%\PCChangeTracker`，设置页显示实际位置。SQLite 本身未加密。密钥由当前用户 DPAPI 保护，复制到其他账户不保证解密。测试新版本前请安全备份。

历史格式 2 将旧快照保留为混合范围并拒绝旧版读取器。管理员辅助进程只接受固定类别和临时密钥副本，不接收历史路径或任意命令；仅普通窗口保存。MSIX 数据生命周期仍需单独验证。

## 无障碍与键盘

Tab/Shift+Tab、方向键和空格操作界面。范围使用独立复选框，模式使用单选按钮。类型及优先级不仅靠颜色，还提供文本。支持清晰焦点及 Windows 高对比度颜色。

F1 打开帮助，Ctrl+F 搜索，Escape 关闭。帮助文字可放大到 160%，窄表格改为带标签的条目。完整读屏验证及母语审校仍待完成。

## 故障排查

日期空白请选择其他观测；比较被拒请核对时间、范围和权限；部分来源不表示删除；旧报告请先执行新选择。数据库打不开时先检查空间、权限和版本，不要无备份删除。

支持请求应使用审阅后的脱敏报告及应用/Windows 版本，不要提供密码、原始数据库或比较密钥。拒绝管理员权限不影响普通检查。
