# ChangeTracker 帮助

开发预览版的离线指南。本应用只观察配置，不修改 Windows，不修复电脑，也不判定电脑是否安全。

## 语言

在**设置 > 语言**中选择语言。选择会保存，并即时更新界面、已打开的帮助、日期和文本报告，不重启、不采集。二十种语言全部离线内置。阿拉伯语、埃及阿拉伯语和乌尔都语内容从右向左显示，导航菜单仍在左侧。

应用名称、用户输入的检查点名称、路径、标识符及原始观测值不翻译。JSON/CSV 保留稳定的英文字段。Windows 和 UAC 对话框使用系统语言。正式发布前仍需母语使用者审校。

## 设置

从导航菜单打开设置。偏好保存在当前历史目录中，重新打开应用时恢复。

- 外观提供浅色/深色主题、字体，以及独立的应用文字、标签、按钮背景和按钮文字颜色。带名称的色样包括默认、海军蓝、森林绿、栗红和紫色。默认恢复该项的主题颜色；Windows 高对比度优先，主要操作始终使用对比鲜明的文字。未保存选择时默认使用深色主题。按钮层级清晰：主检查为青绿色，删除操作为红色，其他命令为带彩色图标的中性按钮（例如报告、更改范围和帮助）。下拉列表、复选框和开关的箭头、勾选标记与焦点边框使用强调色。设置的各个部分按列排列，因此页面通常无需滚动即可在一屏内显示。
- 自动快照默认每 4 小时一次；保留已保存的选择，包括关闭。可选关闭、每 15 分钟、每小时、每 4 小时、每 6 小时、每天或每周。仅应用运行时执行，包括托盘状态，使用普通权限并可取消。确认范围后，首次或过期检查可在下一次每分钟检查任务时执行，之后按所选间隔运行。不请求管理员权限、不唤醒电脑，也不会重放所有错过的间隔。选择关闭可仅手动检查。
- 数据默认保留 30 天；保留已保存的选择，包括永久保留。可选 30、90、180、365 天或永久保留。仅删除超龄、未命名且不是基准的快照。首次到期时清理，之后在应用运行时每天清理，也在成功自动检查后清理；即使自动快照关闭仍有效。命名检查点及所有范围/权限的基准受保护。
- 登录 Windows 时启动为可选项，默认关闭。包括重启电脑后登录，不包括登录前采集。只修改本应用的当前用户启动项，不安装服务或开机任务，不修改其他应用或策略。注册失败时保留原选择。
- 最小化或关闭始终将窗口隐藏到托盘，检查继续进行。打开、双击托盘图标或再次启动应用会恢复窗口。托盘的退出命令取消进行中的工作并结束应用。普通启动默认最大化；从托盘恢复时保留上次可见状态。可选的登录启动会隐藏窗口，重启 Windows 后登录也适用；不会在登录前运行，也不是服务。

简单模式直接显示已更改的公开字段，带有更改前/更改后标签和更大的可选择只读文本。关闭详情后，键盘焦点返回原按钮（如果仍可用）。高级模式将保留的日期与精确采集时间分开，并用独立行显示检查点和范围/权限。切换模式保留所选比较。

新用户默认勾选两个范围，已有选择会保留。无论当前采集范围如何，都能查询保留的所有范围历史，但比较端点必须具有相同范围和权限。任何设置都不会授予管理员权限。资源性能测量和已安装包的生命周期验证尚未完成。

## 开始使用

1. 正常打开，不要以管理员身份启动。
2. 新用户默认勾选当前用户和整个计算机。可以保留任一项或两项，不能全部清除，然后确认。
3. 检查数据源。所有支持的检查默认启用，包括网络和 PATH。已保存的选择保持不变，也可关闭不需要的数据源。改变选项不会开始检查。
4. 选择今天（新检查），再选择立即检查。

第一次可用观测成为该范围及权限的基准。它是当前清单，不能重建过去。新用户默认使用 4 小时间隔，仅在确认范围后且应用运行时采集。选择关闭可仅手动检查。

## 简单与高级

简单显示摘要和文本报告。高级增加所有已采集字段、完整前后值、技术元数据以及 JSON/CSV。两个模式都可比较日期、管理历史和选择数据源。

切换模式不采集、不提权、不移动基准、不额外收费。计划一次性售价 0.99 美元，包含两个模式；预览版没有购买功能。

## 独立范围

用户范围读取本用户应用注册、Run/RunOnce、默认关联、音频、代理和 PATH。计算机范围读取共享注册、服务、任务、更新、驱动、防火墙、DNS/DHCP 和系统 PATH。不加载其他人的私人配置文件。

两项均选中时，都在您自己的账户下使用普通访问分别读取，再保存为合并快照。两个范围都不会获得管理员权限。保留已保存的范围及各范围来源偏好。

## 日期与观测

日期选择器只列出仍保留的快照，显示本地日期、含毫秒的时间、UTC 偏移、检查点及范围/权限。不能输入任意日期，删除或过期的快照会从列表消失。第二个端点可选择保存的快照或今天的新检查。基准按钮只选择普通权限的基准，不替换它。仅当前状态会清除前一个选择。

没有快照的日期无法重建，也不会悄悄换成最近一天。两次观测必须不同、按时间顺序、不重叠，且范围和访问权限一致。

## 两个已保存快照

选择前一个日期和快照，再选择已保存快照及后一个日期和快照。比较快照不会运行采集器、请求 UAC 或创建新记录。基准不变，同一天不同时间也能比较。

## 快照与今天

选择以前的快照与今天。立即检查会创建全新观测，并与明确选中的快照比较，不会暗中换成其他基准。成功后选择面板折叠，可随时重新展开。

早期版本用管理员访问保存的快照不能作为新检查的基准，因为检查始终使用普通访问。请选择普通访问快照或仅当前状态。两个已保存快照仍可彼此比较。取消会停止采集并保留之前的历史。关闭窗口后仍在托盘继续采集；托盘退出会取消并结束应用。

## 管理员访问

ChangeTracker 从不请求管理员访问权限。无论手动还是自动，两个范围的每次检查都使用 Windows 普通权限运行，因此 Windows 不会因为检查显示 UAC 提示。没有管理员模式、提升的辅助进程或后台服务。

许多整个计算机设置可用普通访问读取；如果某个源包含普通权限无法读取的内容，该源会报告为不完整（列在覆盖详情中，绝不建议删除），而不是提升权限。不支持用“以管理员身份运行”启动 ChangeTracker：应用会显示消息并关闭；请正常打开。

早期版本用管理员访问保存的快照仍留在历史中：可以查看、彼此比较并纳入报告，但不能作为新检查的较早快照；请选择普通访问快照或“仅当前状态”。安装 MSI 需要 Windows 管理员批准（仅安装，不是检查）；Microsoft Store 包安装不需要。不要分享管理员密码。

## 查看详细变化

已添加、已移除和已修改描述两个观测端点的差异，不代表确切时间、作者或原因。重要和需检查是优先级，不是恶意软件判定。常规/预期及影响未评估变化分组显示。标题计数遵循当前筛选，可显示前三项以外的所有发现。

高级显示长值、未变化上下文、新增/删除字段、来源和记录身份。元数据包括快照 ID、范围/权限、快照与来源读取的准确 UTC 时间、版本、状态及数量。空值和不存在不同。未保存过的命令无法恢复，比较指纹和密钥永不显示。设备身份可能识别您，复制前请检查。

预期标记仅适用本次事件且可撤销。打开设置只打开允许的 Windows 工具，不执行修复。

## 覆盖与不确定性

成功是已实现子范围完整，并非检查了全部 Windows。部分表示缺项或达到安全限制，失败表示不可用读取，禁用/范围外表示未读取。不能根据不完整数据推断删除。

本次读取完整仍可能与上次不完整或格式/密钥不同的记录无法比较。合并范围中任一部分不完整会使该类别为部分状态。覆盖详情保留基准和未变化区域。没有差异不等于安全或因果结论。

## 基准与历史

快照页可查看、命名（1–120 字符）、删除或经确认更改基准。删除基准前必须选择其他基准。用户、机器、合并范围、不同权限及旧版混合记录分别保留基准。

没有固定检查点上限。可选保留策略清理旧的未命名快照，保护命名检查点和所有基准。所有来源均不可用时不保存。清除历史经确认删除快照和标记，保留偏好及密钥，不改 Windows 或已导出文件；不是取证级擦除。

## 来源与限制

| 来源 | 限制 |
| --- | --- |
| 应用与启动 | 卸载注册和 Run/RunOnce；不枚举 Store、便携应用、启动文件夹。注册不是执行证据。 |
| 服务与任务 | 可读配置；不执行，不保存命令或完整 XML，不持续轮询。 |
| 更新与驱动 | 本地成功历史，最多 5,000 事件，超限为部分；WMI 元数据，无安装、固件探测或回滚。 |
| 默认应用与音频 | 支持的文件关联和默认设备，无录音或改动。 |
| 保护 | 防火墙配置，不是杀毒评估。 |
| 网络与 PATH | 默认启用：代理或 DNS/DHCP 与持久 PATH；无抓包、密码、网络探测或其他环境变量。 |

没有有效的保存选项时，所有支持的数据源默认启用。更新后，曾关闭的数据源仍保持关闭；可在数据源页修改。启用不会立即采集或提升权限。比较需要两个端点都有可用观察；旧快照不会补填后来启用的数据。

每来源最多 25 秒。清单界面每来源显示最多 1,000 条，实际已采集数据全部保存。只读允许写应用自身历史和请求的导出，不修改被观察设置。

## 报告

报告使用当前显示结果，不是尚未执行的日期选择。两个模式都可预览、复制、保存文本，高级增加 JSON/CSV。文本随语言，结构化格式不变，无自动发送。

报告不含密钥、指纹、启动内容、检查点名称及音频端点 ID。用户路径和常见凭据模式会隐藏，CSV 防止公式执行。可识别名称仍可能保留。没有 PDF/HTML、导入、加密支持包。清除历史不会删除导出。

## 隐私与存储

通常路径为 `%LOCALAPPDATA%\PCChangeTracker`，设置页显示实际位置。SQLite 本身未加密。密钥由当前用户 DPAPI 保护，复制到其他账户不保证解密。测试新版本前请安全备份。

### 管理磁盘用量

1. 查看左侧栏帮助上方的快照存储标签。每个页面都显示它，计入当前历史目录的所有范围。
2. 将鼠标停在大小上查看提示。也可用 Tab 聚焦标签；屏幕阅读器可读取名称和帮助文字。
3. 在设置中调整自动检查的频率。更长的间隔产生更少的新快照；关闭仅停止自动采集，不会删除历史，也不停止保留期限清理。
4. 更短的保留期限在下一次到期清理时删除符合条件的旧快照，不是在选择时立即删除。清理在到期时执行，之后应用运行期间每天执行，也在自动采集成功后执行。所有基准和命名检查点受保护，因此不是严格的磁盘空间上限。

大小是存在的 `history.db`、`history.db-wal` 和 `history.db-shm` 文件之和。它包括选项、数据库开销和可重用空闲空间，不只是快照数据，也不是 Windows 按分配单元取整的占用空间。导出文件、应用安装和密钥文件不计入。B、KiB、MiB、GiB 和 TiB 采用 1,024 的倍数，数字按所选语言格式显示。

数值随采集、删除或清理后的历史刷新而更新，不是持续磁盘监控。大小不可用不代表零。删除可能留下可重用空间而不立即缩小文件；空历史也有数据库开销。应用不会自动压缩数据库。应用运行时不要删除数据库或临时文件。

历史格式 2 将旧快照保留为混合范围并拒绝旧版读取器。只有普通访问窗口保存历史。MSIX 数据生命周期仍需单独验证。

## 无障碍与键盘

设置 > 外观 > 文本大小提供 100%、125%、150% 和 200%，保存选项并放大页面、控件、帮助和报告。空间不足时成对字段上下排列；页面、侧栏和对话框可滚动。字体选择也应用到帮助文档；帮助自身的文档缩放仍可达到基础大小的 160%。

侧栏导航会报告当前选中页面，并支持方向键。Ctrl+1 打开更改，Ctrl+2 打开快照，Ctrl+3 打开数据源，Ctrl+4 打开设置。F6 和 Shift+F6 在导航、命令栏和页面标题间切换，Tab 继续进入页面控件。在帮助中，F6 在搜索、主题和文档间切换，Ctrl+F 返回搜索。

范围选择器聚焦第一个复选框，确认后返回更改范围。模态面板会禁用整个侧栏及页面快捷键，Tab 留在面板内。Escape 关闭详情，并在原操作仍可用时恢复焦点。帮助初始聚焦搜索，报告初始聚焦只读预览。快照行、主题、分组和字段具有可读名称；值说明字段及更改前/后，数据源说明状态和范围。主要控件的可交互高度至少为 44 个设备无关单位。

这些支持不是通用无障碍认证。仍需屏幕阅读器、对比度主题、Windows 缩放组合以及残障用户的手动评估。真实键盘测试需要已解锁且不受干扰的会话。

Tab/Shift+Tab、方向键和空格操作界面。范围使用独立复选框，模式使用单选按钮。类型及优先级不仅靠颜色，还提供文本。支持清晰焦点及 Windows 高对比度颜色。

F1 打开帮助，Ctrl+F 搜索，Escape 关闭。帮助文字可放大到 160%，窄表格改为带标签的条目。完整读屏验证及母语审校仍待完成。

标题提供读屏导航层级。打开详情时焦点移入面板；Tab 在面板内循环，Escape 关闭。字体和适应主题的颜色可在设置中更改，Windows 高对比度优先。

## 故障排查

日期空白请选择其他观测；比较被拒请核对时间、范围和权限；部分来源不表示删除；旧报告请先执行新选择。数据库打不开时先检查空间、权限和版本，不要无备份删除。

某些整个计算机设置需要管理员权限；ChangeTracker 会将它们报告为不完整，而不是请求提升权限；其他来源仍会比较。支持请求应使用审阅后的脱敏报告及应用/Windows 版本，不要提供密码、原始数据库或比较密钥。
