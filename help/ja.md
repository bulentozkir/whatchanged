# ChangeTracker ヘルプ

開発プレビューのオフラインガイドです。Windows の構成を変更せず観測します。修復や安全性の判定は行いません。

## 言語

左側の言語を選ぶと保存され、画面、開いているヘルプ、日付、テキストレポートが更新されます。再起動や取得は不要です。20 言語を内蔵しています。アラビア語、エジプトアラビア語、ウルドゥー語は右から左へ表示しますが、メニューは左に残ります。

アプリ名、入力したラベル、パス、識別子、元の値は翻訳しません。JSON/CSV は固定の英語フィールドを保持します。Windows/UAC はシステム言語を使用します。公開前の母語話者による校閲が必要です。

## はじめに

1. 管理者ではなく通常起動します。
2. 新しいプロファイルでは現在のユーザーとコンピューター全体の両方が選択済みです。片方または両方を選び、確認します。ゼロにはできません。
3. 取得元を確認します。ネットワークと PATH は任意で、選択だけでは開始しません。
4. 今日と今すぐ確認を選びます。

最初の有効な観測がその範囲と権限の基準になります。現在の一覧であり、過去の復元ではありません。起動時の取得や常時監視はありません。

## シンプルと詳細

シンプルは要約とテキストを表示します。詳細は全取得フィールド、要約制限のない前後の値、技術メタデータ、JSON/CSV を追加します。日付比較、履歴、取得元は両方で使えます。

切り替えても取得、権限昇格、基準変更や追加料金は発生しません。予定価格は両モード込みで一度きり 0.99 米ドルです。プレビューに購入機能はありません。

## 独立した範囲

ユーザー側は自分のアプリ登録、Run/RunOnce、関連付け、音声、プロキシ、PATH です。コンピューター側は共有登録、サービス、タスク、更新、ドライバー、ファイアウォール、DNS/DHCP、システム PATH です。他人の個人プロファイルを読みません。

両方を選ぶと別々に読み、合成した一つの観測を保存します。明示的に要求した場合だけコンピューター部分を昇格できます。ユーザー部分は元の通常アカウントで実行します。以前の範囲と取得元の選択は維持します。

## 日付と観測

日付はローカルの日で絞り込みます。同日に複数あるので、時刻とチェックポイントも選んでください。基準ボタンは通常アクセスの基準を選ぶだけです。現在の状態のみは前の選択を消します。

観測がない日の状態は復元できず、近い日付に勝手に置き換えません。別の観測で、時間順、重なりなし、範囲と権限が一致している必要があります。

## 保存済み同士の比較

前の日付と観測を選び、保存済みの記録、後の日付と観測を選んで比較します。コレクターも UAC も起動せず、新しい観測を保存しません。基準は変わりません。同日の別時刻でも比較できます。

## 今日との比較

前の観測と今日を選ぶと、新しい状態を取得して選んだ観測と比較します。裏で別の基準に置き換えません。成功後に選択パネルが折りたたまれ、再度開けます。

管理者の基準を選んでも自動昇格しません。別の管理者操作を使うか、現在の状態のみを選びます。キャンセルや取得中の閉じる操作は停止を要求し、既存履歴を残します。

## 管理者アクセス

多くの共有設定は通常権限で読めます。読めない部分は不足として表示します。管理者操作には明示的なクリック、既定で「いいえ」の確認、および一回分の UAC 許可が必要です。

主画面は通常権限のままです。一時的な読み取り専用ヘルパーが機械部分を読み、サービスや永続権限を残しません。拒否しても履歴と基準は変わりません。パスワードを共有したり、組織の保護を無効化したりしないでください。すでに表示された UAC は Windows で応答します。

## 変更の詳細

追加、削除、変更は二つの観測の差であり、実行者、正確な時刻、原因を示しません。重要/要確認は優先順位でありマルウェア判定ではありません。通常/想定内と影響未評価の変更は別グループです。見出しはフィルター内の数で、すべて表示すると最初の三件以降も見られます。

詳細では長い値、変更なしの文脈、追加/削除されたフィールド、記録 ID と取得元が見られます。メタデータは観測 ID、範囲/権限、正確な UTC 取得/読み取り時刻、状態、バージョン、件数です。空と不存在を区別します。保存しなかったコマンドは復元せず、キーや指紋は表示しません。識別子は端末を特定するため、コピー前に確認してください。

想定内のマークは今回のみで取り消せます。設定を開く操作は許可された Windows 画面を開くだけで修復しません。

## 取得範囲と不確実性

成功は実装済みの範囲で完全という意味で、Windows 全体ではありません。一部は欠落や制限、失敗は使えない読み取り、無効/範囲外は未取得です。不完全なデータから削除を推測しません。

今回が完全でも前回の不足、異なる形式やキーのため比較できない場合があります。合成時に片方が不足すればカテゴリ全体も一部になります。範囲詳細には基準と変化のない領域があります。差がないことは安全や因果関係の保証ではありません。

## 基準と履歴

履歴では表示、命名（1～120 文字）、削除、確認付き基準変更ができます。基準を削除する前に別の基準にします。ユーザー、機械、両方、権限別、旧混合データは別の基準を保持します。

自動削除や固定のポイント上限はありません。全取得元が無効なら保存しません。履歴消去は確認後に観測とマークを消しますが、設定とキーを残し、エクスポートや Windows に影響しません。完全消去の保証ではありません。

## 取得元の制限

| 取得元 | 制限 |
| --- | --- |
| アプリと起動 | アンインストール登録と Run/RunOnce。Store、ポータブルアプリ、起動フォルダーは対象外。登録は実行証拠ではありません。 |
| サービスとタスク | 読める構成のみ。実行、コマンド/XML 保存、継続ポーリングなし。 |
| 更新とドライバー | 成功したローカル履歴 5,000 件まで、超過は一部。WMI メタデータのみ。インストール、ファームウェア、ロールバックなし。 |
| 既定アプリと音声 | 対応する関連付けと既定デバイス。録音や変更なし。 |
| 保護 | ファイアウォールプロファイルのみ、ウイルス対策判定なし。 |
| ネットワークと PATH | 任意。プロキシまたは DNS/DHCP と保存済み PATH。パケット、パスワード、ネットワーク探査、他の環境変数なし。 |

取得元ごとに 25 秒です。一覧は各元 1,000 件まで表示しますが、実際に取れた全データを保存します。読み取り専用でも自身の履歴と要求したエクスポートは書き込みます。

## レポート

レポートは表示済み結果を使い、未実行の選択ではありません。両モードでテキストのプレビュー/コピー/保存、詳細で JSON/CSV が使えます。テキストは選択言語、構造化スキーマは不変です。自動送信しません。

キー、指紋、起動内容、チェックポイント名、音声 ID は除きます。プロファイルパスと一般的な資格情報パターンを伏せ、CSV 数式を無害化します。特定できる名前は残る場合があります。PDF/HTML、取り込み、暗号化パッケージは未実装です。履歴を消してもエクスポートは残ります。

## 保存とプライバシー

通常は `%LOCALAPPDATA%\PCChangeTracker` で、設定画面に実際の場所を表示します。SQLite は暗号化していません。キーは現在ユーザーの DPAPI で保護され、別アカウントへのコピーでは復号を保証できません。新しい版の使用前に安全にバックアップしてください。

履歴形式 2 は古い観測を混合として残し、古いアプリでの読み取りを拒否します。ヘルパーはカテゴリと一時キーだけを受け取り、履歴パスや任意コマンドは受け取りません。通常画面だけが保存します。MSIX データのライフサイクルは別途検証が必要です。

## アクセシビリティ

Tab/Shift+Tab、矢印と Space で操作します。範囲は独立チェックボックス、モードはラジオです。優先度と種類は色だけでなく文字でも表示します。明確なフォーカスと Windows 高コントラスト色に対応します。

F1 はヘルプ、Ctrl+F は検索、Escape は閉じるです。ヘルプは 160% まで拡大でき、狭い表はラベル付き項目になります。全読屏環境の検証と母語校閲は未完了です。

## トラブル対応

空の日は別の観測を選びます。比較拒否は順序、範囲、権限を確認します。一部取得は削除を意味しません。古いレポートなら新しい選択を実行します。履歴を開けなければ、削除前に空き容量、権限、版を確認してください。

サポートには確認済みレポートとアプリ/Windows の版を共有し、パスワード、未加工データベース、キーを送らないでください。管理者を拒否しても通常確認できます。

## 公開状況

11 個の限定カテゴリを持つ手動プレビューです。常駐監視、通知、可変保持期間、完全なイベント履歴はありません。取得には資源が必要で、CPU ゼロとは約束しません。

ローカル x64 MSI/MSIX は未署名です。MSI インストール許可は取得同意と別で、両形式を同時に入れないでください。実 UAC、別管理者、Windows 10/ARM64、インストール、Store の `allowElevation` 承認は未検証です。ソース変更だけでは旧インストーラーは更新されません。ロゴは実際のスクリーンショットや認証の代わりにはなりません。
