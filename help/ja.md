# ChangeTracker ヘルプ

開発プレビューのオフラインガイドです。Windows の構成を変更せず観測します。修復や安全性の判定は行いません。

## 言語

**設定 > 言語**で選ぶと保存され、画面、開いているヘルプ、日付、テキストレポートが更新されます。再起動や取得は不要です。20 言語を内蔵しています。アラビア語、エジプトアラビア語、ウルドゥー語は右から左へ表示しますが、メニューは左に残ります。

アプリ名、入力したラベル、パス、識別子、元の値は翻訳しません。JSON/CSV は固定の英語フィールドを保持します。Windows/UAC はシステム言語を使用します。公開前の母語話者による校閲が必要です。

## 設定

メニューから設定を開きます。設定値は現在の履歴フォルダーに保存され、再起動後も復元されます。

- 外観ではライト/ダーク、フォント、およびアプリ文字、ラベル、ボタン背景、ボタン文字の色を個別に選べます。名前付きの色見本は既定、ネイビー、フォレストグリーン、マルーン、パープルです。既定で各項目をテーマ色に戻します。Windows のハイコントラストが優先され、主要操作の文字は読みやすいコントラストを保ちます。保存された選択がない場合はダークが既定です。ボタンは役割で区別されます。メインの確認はティール、削除は赤で、そのほかのコマンドは色付きアイコンを持つニュートラルなボタンです（例: レポート、範囲を変更、ヘルプ）。ドロップダウン、チェック ボックス、スイッチは矢印、チェック、フォーカス枠にアクセント色を使います。設定の各セクションは列に並ぶため、通常はスクロールせずに 1 画面に収まります。
- 自動スナップショットの既定は 4 時間ごとです。オフを含む保存済みの選択は維持されます。オフ、15 分、1 時間、4 時間、6 時間、毎日、毎週から選べます。アプリ動作中のみ、トレイ内でも通常権限で実行され、キャンセルできます。範囲を確認した後、初回または期限超過の確認は次の毎分チェックで始まることがあり、その後は選択した間隔に従います。管理者要求や PC の復帰、すべての未実行間隔の再実行は行いません。手動確認のみの場合はオフを選んでください。
- データの既定の保持期間は 30 日です。無期限を含む保存済みの選択は維持されます。30、90、180、365 日または無期限を選べます。古くて名前がなく基準でもない記録だけを削除します。最初の期限、その後は動作中に毎日、および自動確認の成功後に整理します。自動取得がオフでも整理は動作します。名前付きチェックポイントとすべての基準は保護されます。
- サインイン時の起動は任意で、既定はオフです。PC 再起動後のサインインも含みますが、サインイン前には取得しません。変更するのはこのアプリ自身のユーザー用起動項目だけです。サービスや起動時タスクを作らず、他のアプリやポリシーは変更しません。登録失敗時は以前の選択を保ちます。
- 最小化や閉じる操作は常にウィンドウをトレイに隠し、確認を続けます。開く、アイコンのダブルクリック、再起動で復元します。トレイの終了で実行中の取得をキャンセルして終了します。通常の起動は最大化され、トレイからの復元は最後の表示状態を保ちます。任意のサインイン時起動は非表示で始まり、Windows 再起動後のサインインも対象です。サインイン前には動作せず、サービスでもありません。

シンプルでは変更された公開フィールドを変更前/変更後のラベルと大きな選択可能な読み取り専用テキストで表示します。詳細を閉じると、元のボタンが利用可能ならフォーカスが戻ります。詳細モードでは保存された日付と正確な取得時刻を分け、チェックポイントと範囲/権限を別の行で表示します。モードを切り替えても選択した比較を保持します。

新しいプロファイルでは両範囲が選択済みで、保存した選択は維持されます。現在の取得範囲にかかわらず全範囲の保存履歴を参照できますが、比較の両端は範囲と権限の一致が必要です。設定だけで管理者権限は与えません。資源使用量とインストール済みパッケージの検証は未完了です。

## はじめに

1. 管理者ではなく通常起動します。
2. 新しいプロファイルでは現在のユーザーとコンピューター全体の両方が選択済みです。片方または両方を選び、確認します。ゼロにはできません。
3. 取得元を確認します。ネットワークと PATH を含む対応するすべての確認が既定で有効です。保存済みの選択は保持され、不要な取得元は無効にできます。選択だけでは開始しません。
4. 今日と今すぐ確認を選びます。

最初の有効な観測がその範囲と権限の基準になります。現在の一覧であり、過去の復元ではありません。新しいプロファイルの間隔は 4 時間で、範囲の確認後、アプリ動作中のみ取得します。手動確認のみの場合はオフを選んでください。

## シンプルと詳細

シンプルは要約とテキストを表示します。詳細は全取得フィールド、要約制限のない前後の値、技術メタデータ、JSON/CSV を追加します。日付比較、履歴、取得元は両方で使えます。

切り替えても取得、権限昇格、基準変更や追加料金は発生しません。予定価格は両モード込みで一度きり 0.99 米ドルです。プレビューに購入機能はありません。

## 独立した範囲

ユーザー側は自分のアプリ登録、Run/RunOnce、関連付け、音声、プロキシ、PATH です。コンピューター側は共有登録、サービス、タスク、更新、ドライバー、ファイアウォール、DNS/DHCP、システム PATH です。他人の個人プロファイルを読みません。

両方を選ぶと、自分のアカウントの通常アクセスで別々に読み、合成した一つの観測を保存します。どちらの範囲にも管理者権限は与えません。以前の範囲と取得元の選択は維持します。

## 日付と観測

選択リストは保持中の記録だけを表示し、ローカル日付、ミリ秒を含む時刻、UTC オフセット、チェックポイント、範囲と権限を示します。任意の日付は入力できず、削除済み記録は消えます。後側には保存記録または今日の新しい確認を選べます。基準ボタンは通常アクセスの基準を選ぶだけです。現在の状態のみは前の選択を消します。

観測がない日の状態は復元できず、近い日付に勝手に置き換えません。別の観測で、時間順、重なりなし、範囲と権限が一致している必要があります。

## 保存済み同士の比較

前の日付と観測を選び、保存済みの記録、後の日付と観測を選んで比較します。コレクターも UAC も起動せず、新しい観測を保存しません。基準は変わりません。同日の別時刻でも比較できます。

## 今日との比較

前の観測と今日を選ぶと、新しい状態を取得して選んだ観測と比較します。裏で別の基準に置き換えません。成功後に選択パネルが折りたたまれ、再度開けます。

以前のバージョンで管理者アクセスにより保存されたスナップショットは、新しい確認の基準にはできません。確認は常に通常アクセスで実行されます。通常アクセスのスナップショットまたは現在の状態のみを選んでください。保存済み同士なら比較できます。キャンセルは取得を止め、既存履歴を残します。閉じてもトレイで取得を続け、トレイの終了でキャンセルして終了します。

## 管理者アクセス

ChangeTracker が管理者アクセスを求めることはありません。手動でも自動でも、すべての確認は両方の範囲で Windows の通常アクセスにより実行されるため、確認のために Windows が UAC プロンプトを表示することはありません。管理者モード、昇格ヘルパー、バックグラウンド サービスはありません。

多くのコンピューター全体の設定は通常アクセスで読めます。通常アクセスで読めない内容を含む取得元は、不完全として報告されます（カバレッジ詳細に表示し、削除候補にはしません）。昇格は行いません。ChangeTracker を「管理者として実行」で起動することはサポートされていません。メッセージを表示して終了するため、通常どおり開いてください。

以前のバージョンで管理者アクセスにより保存されたスナップショットは履歴に残ります。表示、相互比較、レポートへの含有はできますが、新しい確認の前側スナップショットにはできません。通常アクセスのスナップショットまたは「現在の状態のみ」を選んでください。MSI のインストールには Windows の管理者承認が必要です（インストールのみで、確認ではありません）。Microsoft Store パッケージは不要です。管理者パスワードは共有しないでください。

## 変更の詳細

追加、削除、変更は二つの観測の差であり、実行者、正確な時刻、原因を示しません。重要/要確認は優先順位でありマルウェア判定ではありません。通常/想定内と影響未評価の変更は別グループです。見出しはフィルター内の数で、すべて表示すると最初の三件以降も見られます。

詳細では長い値、変更なしの文脈、追加/削除されたフィールド、記録 ID と取得元が見られます。メタデータは観測 ID、範囲/権限、正確な UTC 取得/読み取り時刻、状態、バージョン、件数です。空と不存在を区別します。保存しなかったコマンドは復元せず、キーや指紋は表示しません。識別子は端末を特定するため、コピー前に確認してください。

想定内のマークは今回のみで取り消せます。設定を開く操作は許可された Windows 画面を開くだけで修復しません。

## 取得範囲と不確実性

成功は実装済みの範囲で完全という意味で、Windows 全体ではありません。一部は欠落や制限、失敗は使えない読み取り、無効/範囲外は未取得です。不完全なデータから削除を推測しません。

今回が完全でも前回の不足、異なる形式やキーのため比較できない場合があります。合成時に片方が不足すればカテゴリ全体も一部になります。範囲詳細には基準と変化のない領域があります。差がないことは安全や因果関係の保証ではありません。

## 基準と履歴

履歴では表示、命名（1～120 文字）、削除、確認付き基準変更ができます。基準を削除する前に別の基準にします。ユーザー、機械、両方、権限別、旧混合データは別の基準を保持します。

固定のポイント上限はありません。任意の保持期間で古い無名記録を整理し、名前付きチェックポイントとすべての基準は保護します。全取得元が無効なら保存しません。履歴消去は確認後に観測とマークを消しますが、設定とキーを残し、エクスポートや Windows に影響しません。完全消去の保証ではありません。

## 取得元の制限

| 取得元 | 制限 |
| --- | --- |
| アプリと起動 | アンインストール登録と Run/RunOnce。Store、ポータブルアプリ、起動フォルダーは対象外。登録は実行証拠ではありません。 |
| サービスとタスク | 読める構成のみ。実行、コマンド/XML 保存、継続ポーリングなし。 |
| 更新とドライバー | 成功したローカル履歴 5,000 件まで、超過は一部。WMI メタデータのみ。インストール、ファームウェア、ロールバックなし。 |
| 既定アプリと音声 | 対応する関連付けと既定デバイス。録音や変更なし。 |
| 保護 | ファイアウォールプロファイルのみ、ウイルス対策判定なし。 |
| ネットワークと PATH | 既定で有効。プロキシまたは DNS/DHCP と保存済み PATH。パケット、パスワード、ネットワーク探査、他の環境変数なし。 |

有効な保存済み選択がない場合、対応する取得元はすべて既定で有効です。無効にした取得元は更新後も無効のままで、取得元画面で変更できます。有効化だけで取得や昇格は行いません。差分には両端の有効な観測が必要で、古いスナップショットに後からデータを補いません。

取得元ごとに 25 秒です。一覧は各元 1,000 件まで表示しますが、実際に取れた全データを保存します。読み取り専用でも自身の履歴と要求したエクスポートは書き込みます。

## レポート

レポートは表示済み結果を使い、未実行の選択ではありません。両モードでテキストのプレビュー/コピー/保存、詳細で JSON/CSV が使えます。テキストは選択言語、構造化スキーマは不変です。自動送信しません。

キー、指紋、起動内容、チェックポイント名、音声 ID は除きます。プロファイルパスと一般的な資格情報パターンを伏せ、CSV 数式を無害化します。特定できる名前は残る場合があります。PDF/HTML、取り込み、暗号化パッケージは未実装です。履歴を消してもエクスポートは残ります。

## 保存とプライバシー

通常は `%LOCALAPPDATA%\PCChangeTracker` で、設定画面に実際の場所を表示します。SQLite は暗号化していません。キーは現在ユーザーの DPAPI で保護され、別アカウントへのコピーでは復号を保証できません。新しい版の使用前に安全にバックアップしてください。

### ディスク使用量を管理する

1. 左側のヘルプの上にあるスナップショット容量を確認します。すべてのページに表示され、現在の履歴の全範囲を含みます。
2. 容量にポインターを合わせると説明が出ます。Tab でもラベルにフォーカスでき、スクリーンリーダーは名前と説明を読めます。
3. 設定で自動確認の頻度を調整します。間隔を長くすると今後の記録数が減ります。オフは自動取得を止めますが、履歴を削除せず保存期間による整理も止めません。
4. 保存期間を短くすると、対象の古い記録は次の期限到来時の整理で削除されます。選択直後ではありません。整理は期限到来時、その後は動作中に毎日、また自動取得成功後に行われます。基準と名前付きチェックポイントは保護されるため、厳密な容量制限ではありません。

容量は存在する `history.db`、`history.db-wal`、`history.db-shm` の合計です。設定、管理領域、再利用可能な空き領域も含み、記録本体だけのサイズや Windows の割り当て単位に丸めたディスク上のサイズではありません。エクスポート、アプリ本体、鍵ファイルは含みません。B、KiB、MiB、GiB、TiB は 1,024 倍の単位で、数値は選択言語の形式になります。

取得、削除、整理後の履歴更新で表示が変わります。常時監視ではありません。容量を取得できない表示はゼロを意味しません。削除しても再利用可能な領域が残る場合があり、空の履歴にも管理領域があります。自動圧縮はしません。アプリ実行中にデータベースや一時ファイルを削除しないでください。

履歴形式 2 は古い観測を混合として残し、古いアプリでの読み取りを拒否します。履歴の保存は通常アクセスの画面だけが行います。MSIX データのライフサイクルは別途検証が必要です。

## アクセシビリティ

設定 > 外観 > 文字サイズでは 100%、125%、150%、200% を選択して保存でき、ページ、操作部、ヘルプ、レポートの文字を拡大します。狭い場合は対のフィールドを縦に並べ、ページ、サイドバー、ダイアログをスクロールできます。フォント選択もヘルプ文書に適用され、ヘルプ独自の文書倍率は基準サイズの 160% まで使えます。

サイドバーの移動リストは選択ページを通知し、矢印キーで操作できます。Ctrl+1 は変更、Ctrl+2 は記録、Ctrl+3 は取得元、Ctrl+4 は設定を開きます。F6 と Shift+F6 は移動リスト、コマンド部、ページ見出しを巡回し、Tab でページの操作へ進みます。ヘルプの F6 は検索、トピック、文書を巡回し、Ctrl+F は検索に戻ります。

範囲選択は最初のチェック欄にフォーカスし、確認後は範囲変更へ戻ります。モーダル表示中はサイドバー全体とページのショートカットが無効で、Tab は内部に留まります。Escape は詳細を閉じ、元の操作が利用可能ならフォーカスを戻します。ヘルプは検索、レポートは読み取り専用プレビューから始まります。記録行、トピック、グループ、フィールドは読みやすい名前を持ち、値は項目と前後、取得元は状態と範囲を示します。主要操作部の高さは少なくとも 44 デバイス非依存単位です。

これは包括的な適合認証ではありません。スクリーンリーダー、コントラストテーマ、Windows の倍率、障害のある利用者による手動評価が必要です。実キーボードの試験にはロック解除された、操作を妨げないセッションが必要です。

Tab/Shift+Tab、矢印と Space で操作します。範囲は独立チェックボックス、モードはラジオです。優先度と種類は色だけでなく文字でも表示します。明確なフォーカスと Windows 高コントラスト色に対応します。

F1 はヘルプ、Ctrl+F は検索、Escape は閉じるです。ヘルプは 160% まで拡大でき、狭い表はラベル付き項目になります。全読屏環境の検証と母語校閲は未完了です。

見出しにはスクリーンリーダー用の階層があります。詳細を開くとフォーカスがパネル内へ移り、Tab は内部を循環し、Escape で閉じます。フォントとテーマ対応の色は設定で選べます。ハイコントラストが優先されます。

## トラブル対応

空の日は別の観測を選びます。比較拒否は順序、範囲、権限を確認します。一部取得は削除を意味しません。古いレポートなら新しい選択を実行します。履歴を開けなければ、削除前に空き容量、権限、版を確認してください。

コンピューター全体の一部設定には管理者権限が必要です。ChangeTracker は昇格を求めず不完全として報告し、他の取得元は比較します。サポートには確認済みレポートとアプリ/Windows の版を共有し、パスワード、未加工データベース、キーを送らないでください。

## 公開状況

11 個の限定カテゴリ、手動または任意の定期確認、保持期間設定を持つプレビューです。連続的なイベント監視、通知、完全なイベント履歴は未実装です。取得には資源が必要で、CPU ゼロとは約束しません。

ローカル リリースには未署名の x64 と ARM64 MSI インストーラー、および未署名の x64 MSIX バンドルがあります。MSI のインストールには管理者承認が必要ですが、インストール後のアプリは常に通常権限で動作します。署名、Store 認証、Windows 10/ARM64 の適合確認、インストール/アップグレード/アンインストールの適合確認は未完了です。ソース変更だけでは旧インストーラーは更新されません。ロゴは実際のスクリーンショットや認証の代わりにはなりません。
